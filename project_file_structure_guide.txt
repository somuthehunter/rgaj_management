ARCHITECTURE STYLE USED
- Page/component files focus on TSX structure and composition.
- Business logic and handlers live in dedicated hooks.
- Types are extracted to dedicated types files.
- API details stay in services.
- Validation rules stay in schemas.
- Reusable UI controls are shared under components/shared and components/ui.
- Mock implementations should stay isolated inside services so the UI can later switch to real APIs with minimal churn.
