CURRENT MIGRATION SUMMARY
- Next.js App Router foundation is established.
- Login, Dashboard, Overview, Products, Categories, Inventory, Orders, Customers, Transactions, Sell, Stores, and Users routes are now mapped.
- Shared table rendering and list control patterns are being reused across most dashboard modules.
- Billing flow now creates mock orders and feeds related dashboard modules.
- Stores and Users now follow the same modal/form/mutation pattern as the other CRUD-style sections.
- Some modules still rely on mock data or mock mutations until backend APIs are finalized.
- The project is actively being converted from a Lovable-generated React frontend into a more organized Next.js structure.
