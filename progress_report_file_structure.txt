CURRENT MIGRATION SUMMARY
- Next.js App Router foundation is established.
- Login, Dashboard, Overview, and Products routes are already mapped.
- Products feature is the most complete and modularized section so far.
- Shared table rendering has been extracted into a reusable `DataTable` component for use across multiple pages.
- A developer usage note has been added for the shared table so future contributors can follow the same pattern.
- Dashboard sidebar behavior has been improved for small screens and now defaults to a collapsed icon-first state.
- Shared UI, schemas, services, constants, routes, and types are already separated into dedicated folders.
- The project is actively being converted from a Lovable-generated React frontend into a more organized Next.js structure.
